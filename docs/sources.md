## 기준 문서

**단원수업설계_국악사큐레이팅_주정화.hwtx** / 작성자: 주정화 / 사용자 제공 파일.

완성된 원안의 본문을 기준으로 개요·목표·평가·8차시 계획·5차시 본시를 재구성했다. 원본 문서의 양식 작성 안내와 가상 과제 안내는 문서 내용으로 취급했으며, 외부 기관의 지시나 실제 모집으로 실행하지 않았다. 학교명은 원안에 없어 추가하지 않았다.

## 보존한 핵심 조건

- 대상 중학교 2학년, 총 8차시, 본시 5/8차시.
- 성취기준 [9음02-02], [9음02-03], [9음02-05]. 원안 성취수준 분석표의 중심은 뒤의 두 기준.
- 핵심 개념: 연결, 변화와 지속, 음악적 특징, 맥락, 재해석, 정체성, 큐레이팅.
- 최종 결과물: 시대 비교 매트릭스 + 카드뉴스 10~20장 또는 영상 1~3분 + 발표.
- 평가: 데이터 수집·분류 30점 / 의미 해석 30점 / 구조화·시각화 20점 / 태도·가치 20점.
- 과제 1 30점 + 과제 2 70점 = 100점. 동료평가는 피드백 자료.
- 본시 45분: 도입 5분, 전개 12+10+10분, 정리 8분. 5분 성찰은 정리 시간 안에 포함.
- AI 해석 전 모둠 해석 작성, 사료 교차 검증, 일반화 문장을 사실 사례 두 가지로 뒷받침.
