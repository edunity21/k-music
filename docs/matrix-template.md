# 시대 비교 매트릭스 · 작성용

[학생 활동지](worksheet.md) · [본시 지도안](unit-plan.md#5-본시-수업-설계--58차시) · [소개](../README.md)

> 원안의 ‘가로 시대 × 세로 음악 요소’ 구조로 만든 빈 양식입니다. 감상과 조사로 직접 채우며, 각 사실에 출처 번호를 붙입니다. 완성된 역사 정보표가 아닙니다.

**기록 방법:** 필요하면 삼국의 국가별 사례나 조선 전기·후기의 차이를 칸 안에 구분하거나 열을 추가합니다. 유산의 유래·전승 시기와 오늘날의 유네스코 등재 시기를 혼동하지 않도록 관련성의 근거를 씁니다. 자료가 없으면 추측으로 채우지 말고 ‘확인 필요’로 남깁니다.

## 변화와 지속 표시

| 표시 | 의미 | 선택한 칸과 판단 근거 |
| --- | --- | --- |
| 파랑 + ‘변화’ | 시대 사이에 달라진 요소 | |
| 회색 + ‘지속’ | 비교한 시대에서 이어지는 요소 | |
| ‘확인 필요’ | 근거가 부족하거나 자료가 충돌함 | |

*원안의 파랑·회색 표시는 스프레드시트의 셀 색 또는 조건부 서식으로 적용할 수 있습니다. 이 Markdown 파일에는 자동 색상 기능이 없으므로 글자 표시를 함께 사용합니다.*
